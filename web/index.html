Optional CAPTCHA API

Manual solving above is free. The optional NopeCHA adapter supports one static reCAPTCHA grid round only. It does not support Turnstile, hCaptcha, dynamic grids, or phone verification. NopeCHA’s free tier excludes non-residential IP addresses, so do not expect it to be free on Render.

3 · Create and save your key

  1. Open Developers → API Keys in the remote browser.
  2. Click Create Key, name it, choose only required permissions, and set a credit limit.
  3. For single-account mode, review and confirm creation yourself. Batch mode uses the permissions authorized above.
  4. Click the new key’s Copy button in the screenshot. Then read the remote clipboard below.

ElevenLabs only shows the full key at creation. Reading the clipboard does not validate whether it contains an API key.

Downloaded files are plaintext secrets. Store securely; don’t upload them to GitHub or Supabase.
